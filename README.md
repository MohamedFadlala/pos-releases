# Holool POS releases

Official Windows installers and automatic-update files for Holool POS.

Download the latest Setup installer from [Releases](https://github.com/MohamedFadlala/pos-releases/releases/latest). Existing 0.1.0 installations need a one-time manual installation of 0.1.1 to enable future automatic updates.

Automatic updates check in the background. Administrators can manage updates in Settings > Backup and choose when to restart and install. A verified database backup is created before installation.

This repository hosts release documentation and distribution files. The application requires a valid Holool POS license or trial.
